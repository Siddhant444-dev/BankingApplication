SECURITY NOTES

What the server can—and cannot—see

HIDDEN
Document contents and names

PDF bytes and filenames are encrypted in the browser with AES-256-GCM before storage.

HIDDEN
Plaintext search terms

Search keywords are transformed locally using HMAC-SHA-256. The API receives only fixed-length opaque tokens.

LEAKS
Equality, access and result patterns

Deterministic keyword tokens reveal when the same keyword is queried again. The server can observe which documents match, result counts, timing, and upload sizes.

NOTE
Prototype, not production security

This is a single-user educational demo. The API is not tenant-authenticated, metadata and traffic patterns are not padded, browser local storage holds the workspace salt, and recovery/rotation are not implemented. Do not store sensitive real documents or expose this demo publicly.

Key derivation: PBKDF2-HMAC-SHA-256 · 310,000 iterations · 128-bit workspace salt · separate 256-bit AES and HMAC keys.
